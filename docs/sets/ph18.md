## 7. Edge cases & gotchas

- **Name-year offset:** "2018" released 2019-08-01 (as `ph19` released 2020).
- **Card-count mismatch** (5 vs 4) — see §1. Don't treat the set as
  incomplete because of it.

  (Optimus Prime, Hero // Autobot Leader); different oracle.
