## 7. Edge cases & gotchas

- **CN order is by colour, not by deck**, so a deck can't be selected by CN
  range; use the MTGJSON decklists (`BrazenCoalition_E02`, `LegionOfDusk_E02`,
  `RiverHeralds_E02`, `SunEmpire_E02`).
- **MTGJSON types the decks `Theme Deck`.** That type is not in
  `PRECON_MODERN_TYPES`, so they don't appear in `mm set precon-list` by
  default (`--all-physical` shows them).
- The game also ships tiles, dice and tokens that aren't Magic cards; none are
  in Scryfall.
