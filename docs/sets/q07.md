> **A precon product, not a card set.** The four 2022 Challenger Decks are
> Standard-format reprints whose cards keep their ORIGINAL set codes (MID, VOW,
> NEO, KHM, …). Scryfall's `q07` holds only the one product-exclusive token.
> Track the decks as precons (`mm deck add-precon` / `mm set precon-list`, type
> `Challenger Deck`), not through `set:q07`.

## 7. Edge cases & gotchas

- **Deck cards aren't in `q07`.** MTGJSON's four `*_Q07` decks reference cards
  in their original sets, so `set:q07+related` shows only the token. Owning a
  Challenger Deck never makes `q07` look "complete" beyond that token.
- `T12` is a non-numeric CN (casts to 0 in numeric sorts).
- Unpriced on Scryfall.
