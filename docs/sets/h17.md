## 7. Edge cases & gotchas

- **The token is in the parent set** (CN 4, `is_token = 1`), as in `gs1`/`e02`.
- **Grimlock is a transforming DFC**; its back face is *Grimlock, Ferocious
  King*.
- MTGJSON: sealed product *2017 Magic The Gathering Hascon Collection*
  (`box_set` / `other`), decklist `Hascon2017PromoCards_H17` (`type: Box Set`,
  so it appears in `mm set precon-list`).
