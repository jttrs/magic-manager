> *Heroes of the Realm* run — 4 one-off tribute legendaries printed outside

## 7. Edge cases & gotchas

- **Name-year offset:** "2021 Heroes of the Realm" released 2022-08-01, except
  CN 2 Arteeoh whose card date is 2021-12-25.
- **Universewalker:** CN 3 Byode is typed `Legendary Universewalker` (the
  Universes Beyond planeswalker joke) and is the family's only `universesbeyond`
  print, which is why it carries the triangle security stamp.
- **`set_type: funny`** — not tournament-legal; included in master-list set
  types, so the cards appear in checklists and Collection.
- **Unpriced:** every value report shows these as `—`.
- All `games: [paper]`; no digital, meld, token or serialized prints.
