## 2. Treatments

C21 has exactly ONE fancy tier and **no fancy-foil sheet**: 80 `boosterfun` prints (c21 CN 328–407), all `extendedart` — the same-art extended-art twins of the ~80 NEW AFR Commander cards (new commanders + new support). Everything below CN 328 is regular-frame reprints.

| promo_type / frame | Treatment keyword | Dupe of a sibling? | Notes |
|---|---|---|---|
| `extendedart` (boosterfun, CN 328–407) | `ext` | no — distinct treatment class | the new-card premium tier; captured by the `ext` treatment class (`frame_effects: extendedart`), NOT a foil dupe |
| (no surgefoil/halofoil/textured/serialized) | — | — | 2021 Commander product predates fancy-foil sheets |

**Full-art convention:** standard — borderless/extended prints carry their frame effects; no UB full_art flip.

**`FAMILY_DUPE_FOIL_PROMO_TYPES["c21"] = frozenset()`** — there is no same-art fancy-**foil** sheet to dedup. The empty set is what unblocks `treatment=preferred` / `mm query missing-set c21` (the preferred filter refuses to run for an unconfigured anchor); it filters nothing. The ext-art tier is a distinct treatment class handled by the normal `ext`/`preferred` machinery, not dupe-foil dropping.

## 7. Edge cases & gotchas

- **Reprint-heavy, but NOT a grab-bag.** ~190 of the 270 missing prints are regular-frame reprints from across Magic. Unlike cmm/plst (tagged NON_FAMILY because "missing" = an unbounded reprint pool), c21's reprints are a *bounded, low-value tail* of one coherent product, and its value is concentrated in the ~80 new-card ext-art tier — so it's a real (if modest) completion target, hence CHARACTERIZE not NON_FAMILY.
- No digital/Alchemy set (`yc21` doesn't exist); no serialized tier; no meld backs.
