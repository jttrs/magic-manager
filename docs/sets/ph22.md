# `ph22` — `2022 Heroes of the Realm`

> Per-family memory doc. Read this before answering set-specific questions about
> `ph22` or working on `ph22`-related commands. When new peculiarities emerge in
> chat, update the appropriate section here. See `CLAUDE.md` § "Per-set knowledge".

**Anchor code:** `ph22`
**Family root type:** `funny` (non-tournament-legal special-distribution cards)
**Family released:** 2023-08-01 (Scryfall date; the "2022" in the name is not the release year)
**Last audit:** 2026-11-01 (re-verified 2026-11-02) via `/characterize-set ph22` (non-interactive batch run).

---

> **Special product, not a retail set.** `ph22` is one year of WotC's annual
> *Heroes of the Realm* run — 5 one-off joke/tribute
> legendaries printed outside retail distribution (never in boosters, no
> Scryfall prices). It is a standalone set (`parent_set_code: null`), NOT a bonus
> sheet of any other family. The other years are separate single-set families
> with the same shape: `phtr` (2016, 3), `ph17` (3), `ph18` (5), `ph19` (7),
> `ph20` (3), `ph21` (4), `ph23` (2) — no docs for them yet.

## 5. Unobtainable rules

No rule is active. No alt-treatment tier exists, so there is no keep/exclude
decision to make on treatments.

**Whole-family obtainability (pending owner review).** These cards were never
sold at retail and Scryfall carries no USD price for any of them (`usd` and
`usd_foil` both null). `mm query show 'set:ph22+related missing'` lists all 5
mythics at `—` value. The missing-$ total is therefore $0 — not because the set
is cheap but because it is unpriced; the 5 rows are a completion target only if
the owner deliberately collects Heroes of the Realm cards. If not, the honest
treatment is to leave the family unconfigured / un-tracked rather than add a
rule (a `[[unobtainable.ph22.rules]]` entry with `collector_numbers = ["1","2","3","4","5"]`
would just empty the family).

**Missing-set baseline (2026-11-01):** 5 distinct prints / $0.00 priced (all
unpriced); 0 owned. `mm query missing-set ph22` currently refuses (no `[dupe_foil]`
entry); an empty `ph22 = []` would unblock it and filters nothing.

## 7. Edge cases & gotchas

- **Name-year offset:** "2022 Heroes of the Realm" released 2023-08-01 (each
  year's set lands ~one year after its name year; `ph23` landed 2025-08-24).
- **`set_type: funny`** — not legal in sanctioned formats; rules text is
  joke/meta (opening boosters mid-game, "nostalgic" cards, donating permanents).
  `sets.py` includes `funny` in its master-list set types, so the 5 cards DO
  appear in checklists and in the Collection view.
- **Unpriced:** every value-based report (set-status, missing $, deck/market
  cost) shows these as unpriced / `—`; never read a $0 missing total as
  "complete" or "worthless".
- No digital-only/arena-stamped prints (`games: [paper]` on all 5); no meld
  backs, tokens, or serialized prints.
