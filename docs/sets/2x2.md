## 7. Edge cases & gotchas

- **Etched prices aren't stored locally:** the `cards` table has no etched price
  column, so 413–572 show `—` in value reports even though they have a market.
- **CN 332 Cryptic Spires** is a lone inverted-frame black-border common between
  the base set and the borderless run; don't mistake it for a borderless print.
- **Wrenn and Six 574** (textured) has no frame effects and computes plain `ff`,
  unlike the other four textured titans/Liliana (`b|ff`).
- The Eldrazi titans (Emrakul 1/335/413/575, Kozilek, Ulamog) each have four
  `2x2` prints — confirm the CN when adding.
