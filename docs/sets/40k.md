## 1. Family map

`40k` is a **Universes Beyond Commander-deck product** — 4 preconstructed
Commander decks (Warhammer 40,000), **no draft/set/play boosters**. This is the
`ncc`/`tmc`-style commander-product shape, not a standard expansion. The parent
Scryfall record's `set_type` is `commander` (verified), and it carries a `null`
`parent_set_code` (it is its own root — like the UB Marvel/Avatar roots).

| Code | `set_type` | Cards (EN synced) | Released | Notes |
|---|---|---:|---|---|
| `40k` | commander | 617 | 2022-10-07 | parent — the 4 decks + their Collector's Edition (surgefoil) twins + oversized display commanders, all filed in ONE Scryfall code |
| `t40k` | token | 31 | 2022-10-07 | tokens (0-local — not synced by a bare `sync 40k`) |

`mm set list-related 40k` returns exactly `40k` + `t40k`. There is **no `p40k`
promo code** (no prerelease/promo-pack channel — commander products don't get
one) and **no separate Collector's Edition set code** — the CE cards live INSIDE
`40k` as the `surgefoil` sheet (see §product-types / §2). Default
`set:40k+related` resolution works.

**The 4 decks** (each a `Commander Deck`, MTGJSON `type: Commander Deck`):

## 2. Treatments

`selectors.FAMILY_DUPE_FOIL_PROMO_TYPES["40k"]` — **recommend `frozenset({"surgefoil"})`** (see §8/§9).

Only three non-`universesbeyond` promo_types occur (`universesbeyond` = 617/617,
the UB product constant, not a treatment signal):

| promo_type | Freq | Treatment keyword | Dupe of a sibling? | Notes |
|---|---:|---|---|---|
| `surgefoil` | 308 | `ff` (304) / `b\|ff` (4, the thick display twins) | **yes → DUPE_FOIL** | The **Collector's Edition** foil sheet — every card gets a surgefoil twin. Same art as its plain-frame base sibling (verified Abaddon 2 (surgefoil, `ff`) ↔ 171 (base, `regular`); Aberrant 86★ ↔ 86). |
| `thick` | 8 | `b\|ff` | n/a (oversized display) | The 4 oversized display commanders in foil (177-180, `thick+surgefoil`) + nonfoil (318-321, `thick`). `frame_effects: legendary+inverted+etched`. Each surgefoil display (178, `b\|ff`) dupes its nonfoil twin (319, `b\|ff`) → also caught by the surgefoil DUPE_FOIL rule. |
| `release` | 1 | `regular` | n/a | Fabricate (CN 181, rare) — the release-event promo (Buy-a-Box-style). Low value; in scope, no rule needed. |

**Why surgefoil here is a CLEAN FIN-style DUPE_FOIL (not the msh frame-mismatch):**
the surgefoil print computes to bare `ff` (plain frame) and its same-art base
sibling computes to `regular` (empty), so both key to `(name, no_ff=frozenset())`
in `_filter_treatment_preferred` Step 3 — they pair. `only_in_me = {surgefoil}` ⊆
the dupe set → dropped. Contrast msh, where the surgefoil twin's non-foil sibling
was `ext`-framed so the keys never aligned (forcing a §5 wholesale rule). Here the
base is plain, so `surgefoil` in DUPE_FOIL is exact — verified all 308 surgefoil
prints pair, and `preferred` yields 0 rows at current (near-complete) ownership.

**Full-art convention:** all 617 prints are `full_art: false`, `border_color:
black` — this is a 2022 product, pre-dating the newer UB borderless-inverted
full-art convention (SPM/TLA/TMT). No borderless showcase tier.

**Collector-number structure:** plain-CN base prints CN ~9-317 (305 cards) +
nonfoil thick 318-321; surgefoil twins carry a `★` suffix (296 of them, e.g.
`86★`) OR a low plain CN (1-8, the marquee cards like Szarekh 1 / Abaddon 2).
296 `★`-CN prints, 321 plain-CN.

## 3. Chase variants

**No art-chase.** `_modifier_chase` fires (42 rows) only on the reprinted
Commander utility staples that appear ~3× across the 4 decks at different CNs —
**Arcane Signet** (227/228/229 + `★` surgefoil twins), **Commander's Sphere**
(233-235), **Sol Ring** (249-251), etc. That's reprint-multiplicity of a fixed
card, not distinct-art chase; each is base + surgefoil only.

`uncommon rarity=uncommon treatment=regular chase` → **0 rows** (no uncommon
art-chase). The 4 face commanders have only base + oversized-display prints (in
different treatment classes), so they don't trip the same-`(name,treatment)`
chase detector. `mm query missing-set 40k`'s `uncommon-chase` sub-selector is a
no-op for this family.

## 5. Unobtainable rules

`selectors.FAMILY_UNOBTAINABLE_RULES["40k"]` — **none needed.**

The one candidate scarcity tier — the 308 `surgefoil` Collector's Edition foils
(the entire missing $, see below) — is handled cleanly by DUPE_FOIL (§2), NOT by
an unobtainable rule: each surgefoil is a same-art dupe of an owned/base sibling,
so the standard dupe-foil drop removes them and keeps the base as the preferred
representative. No headliner / serialized / masterpiece / stamped tier exists in
this family (0 prints of each). No arena/rebalanced digital tier (validated — 0
leaks). The lone `release` promo (Fabricate 181) is a normal in-scope card.

**Missing-set impact (before → after configuring `surgefoil` DUPE_FOIL):**

- `set:40k+related missing` (any treatment): **309 rows, $2,331.01** at current ownership.
- Of that, the `alt` (non-empty-treatment) tier is **308 rows, $2,323.78** — essentially the entire surgefoil Collector's Edition sheet (top prints: Ghyrson Starn 124★ ~$108 foil, Marneus Calgar 8 ~$77, Bloodthirster 73★ ~$58).
- `treatment=collectible-alt` already excludes pure-`ff` surgefoil (the `codes != {"ff"}` guard), leaving only the 4 `b|ff` thick surgefoil display commanders (177-180, ~$7.29).
- With `FAMILY_DUPE_FOIL_PROMO_TYPES["40k"] = {"surgefoil"}`, **`treatment=preferred` → 0 rows / $0.00** — every alt print is a surgefoil dupe (incl. the 4 thick display twins, which dupe their nonfoil 318-321). Correct: the user owns the base cards; the CE foil sheet is same-art dupe the user isn't chasing as "missing distinct printings".

So the effect of the proposed diff is purely to **unblock `preferred`** (which
currently errors as unconfigured) and correctly drop the surgefoil dupes — before:
error; after: 0 preferred rows. The rare/mythic-regular and treatment=regular
sub-selectors of `missing-set` continue to track base-card completion normally.

## 7. Edge cases & gotchas

- **Commander-product shape, not an expansion** — `40k`'s `set_type` is
  `commander` and its `parent_set_code` is `null`; it is its own root. Don't
  assume "expansion" defaults. There are no boosters (see §product-types /
  §booster-types — no MTGJSON booster data).
- **Collector's Edition is folded into the SAME Scryfall code** — unlike modern
  UB commander sets (e.g. `msh`/`msc`) where CE decks are separate MTGJSON
  products under a `commander` sibling code, the 2022 `40k` CE variant is the
  `surgefoil` sheet *inside* the `40k` Scryfall code. The 4 CE decks are distinct
  MTGJSON `Commander Deck` products (`…CollectorSEdition_40K`) but their cards all
  share the `40k` set code.
- **surgefoil is a clean DUPE_FOIL (base is plain-framed)** — not the msh-style
  frame-mismatch. Base computes `regular`, surgefoil computes `ff`, so both key to
  `no_ff = frozenset()` and pair in Step 3. This is why `surgefoil` belongs in
  DUPE_FOIL, not a §5 wholesale rule (contrast msh, mat, neo).
- **`★` collector numbers** — 296 surgefoil prints carry a `★` suffix (`86★`),
  8 marquee ones use low plain CNs (1-8). `cn_sort_key` handles the `★` correctly.
- **No digital / serialized / headliner / masterpiece tier** — validated 0 of
  each; no scarcity artifact requiring an unobtainable rule.
- **tokens (`t40k`) not synced by default** — `sync 40k --include-related`.
